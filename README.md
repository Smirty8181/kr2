# Library Desk

Настольное приложение для учёта книг и выдачи читателям, созданное на WPF и C#.

## Возможности

- Регистрация и вход пользователя.
- Просмотр каталога книг.
- Добавление, редактирование и удаление записей.
- Выдача и возврат книг с отображением статуса.
- Хранение данных через Entity Framework Core и SQLite.

## Технологии

C# 12, .NET 8 for Windows, WPF, Entity Framework Core, SQLite.

## Запуск

Откройте `kr2.sln` в Visual Studio с установленной поддержкой .NET Desktop или выполните:

```powershell
dotnet build kr2.sln
```

Приложение рассчитано на Windows. База в репозитории не содержит пользовательских записей; для реальной эксплуатации настройте собственное хранилище и учетные данные.
